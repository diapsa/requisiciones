# Requisiciones

Sistema interno para gestionar las requisiciones de viáticos y su comprobación de gastos, que hoy se manejan en Excel.

## Alcance

- **Requisición:** solicitud de anticipo por conceptos (traslado, casetas, alimentos, hospedaje, materiales, etc.) con autorización del coordinador y de administración.
- **Comprobación:** registro de facturas y tickets por categoría, comparación contra lo autorizado y cálculo del saldo final.

## Stack

- Laravel
- Inertia.js + React + TypeScript
- Tailwind CSS
